# Conventions

This project hasn't written its conventions down yet. `jfl init` proposes a conventions Guideline from the project's toolchain; once the person approves it, it replaces this one.

Until then:

- Read the README, and any CONTRIBUTING or documentation it points to, before changing code.
- Follow the code around the change: its naming, its layout, how it handles errors, how its tests are written.
- Run the project's tests and linter the way its build files do, and keep them passing.
- Add no dependency, tool or pattern the project doesn't already use without asking the person.
