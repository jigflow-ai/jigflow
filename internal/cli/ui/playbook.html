Connectors

The executables that keep an Artifact Type's Artifacts in an outside tracker, the settings each is sent as they are, every one it describes shown whether set or not, and the label or state each Status and field value is mapped to, by default a label of its own name; mapping one to another relabels the Artifacts carrying the old one. The project's declaration of a Connector replaces its Base Playbook's whole, so changing one the Base declares copies it into the Playbook file first. A token never is among them: a Connector reads it from its environment.
